# Security Policy

## Supported versions

Only the latest release (and `main`) receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately via
[GitHub Security Advisories](https://github.com/timzifer/stilus/security/advisories/new).

stilus processes untrusted geometry (for example from PDF files), so reports
of panics, hangs, unbounded memory or CPU use on crafted input are in scope.
You can expect a first response within a week.
